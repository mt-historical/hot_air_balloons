# Overview
This client-side mod for [Hot Air Balloons](https://github.com/mt-historical/hot_air_balloons) adds minor aesthetic improvements when used with [Mineclonia](https://content.luanti.org/packages/ryvnf/mineclonia/) and the halon [build of Luanti](https://codeberg.org/halon/Minetest) and the halon [csm](https://codeberg.org/halon/mcl_localplayer/).

# Installing

To install, copy directory `csm_hot_air_balloons/` to `.minetest/clientmods/` and add this entry to `.minetest/clientmods/mods.conf`:

    load_mod_csm_hot_air_balloons = mods/csm_hot_air_balloons
